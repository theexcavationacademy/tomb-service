# TOMB SERVICE

Act One. A cursed temple, a four-hundred-year-old guardian, and a man in a
gilet filming all of it for content.

One file. Open `index.html` and it runs — offline too.

## Controls

Gamepad: left stick move, right stick look, A jump, X hit, B use.
Keyboard: WASD, mouse to look (click the game first), Shift run, Space jump,
F hit, E use. On a phone: two thumbsticks and four buttons.

## Notes

Dialogue never stops the game — lines appear, clear themselves, and the
browser reads them aloud. 🔊 VOICE in the top bar turns that off.

Every word in the game lives in `story.js` in the source. The music is twelve
original tracks performed live by oscillators; nothing is sampled.
